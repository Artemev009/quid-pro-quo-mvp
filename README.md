# Пульс Бизнеса — демонстрационный MVP

Рабочий прототип пути от потребности малого бизнеса до учебного результата заявки. Сделан для обсуждения кейса «Умный кредитный кабинет предпринимателя» на чемпионате.

## Быстрый запуск

Откройте `index.html` в браузере. Для запуска через Docker: `docker compose up --build`, затем откройте http://localhost:8080.

## Как проверить

1. На главной странице нажмите «Подобрать кредит» или выберите карточку цели.
2. Меняйте цель, сумму и срок: предложение справа обновляется.
3. Нажмите «Продолжить заявку» и заполните форму. ИНН — 10 или 12 цифр.
4. Отправьте заявку и посмотрите результат в разделе «Моя заявка».
5. Для демонстрации разных исходов: сумма более 5 млн ₽ ведёт к ручной проверке; при меньшей сумме выручка ниже 300 тыс. ₽ вызывает запрос сведений; остальные примеры дают предварительное предложение.

Данные сохраняются в `localStorage` текущего браузера. Это учебные правила, не скоринг или условия Альфа-Банка. Реальных кредитов, внешних проверок, входа в банк и отправки персональных данных нет.

## Устройство

Статический HTML/CSS/JavaScript, без платных сервисов и зависимостей. `index.html` содержит четыре экрана, `script.js` управляет переходами и состоянием, `styles.css` задаёт оформление. Docker использует nginx как статический сервер.

Следующий шаг после звонка: база данных, клиентская и банковская роли, запрос документов, история состояний, API и полная документация по требованиям кейса.
