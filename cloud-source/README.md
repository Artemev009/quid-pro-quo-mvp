# Публичная серверная версия

Здесь лежит серверная логика опубликованной версии на Sites: `api/route.ts` соответствует `app/api/[...path]/route.ts`, а `db/schema.ts` и `drizzle/0000_initial.sql` описывают таблицу заявок в D1. Клиентские файлы совпадают с корнем этого репозитория. Для отдельной сборки используется стандартный Vinext starter Sites; переменная `BANK_DEMO_PIN` задаётся секретом на хостинге и не хранится в репозитории.

Локальная версия из корня репозитория работает без облачных зависимостей через `node server.js`.
